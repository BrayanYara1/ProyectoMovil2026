# Project Backlog - MVP 01-week

Este backlog contiene las Historias de Usuario (HU) esenciales para la primera iteración.

## MVP 01-week (Fundamentos)

### HU-001: Autenticación de Usuario (Login)
**Criterios de Aceptación:**
- [ ] El usuario puede ingresar usuario y contraseña.
- [ ] Validación contra `users.json`.
- [ ] Redirección al dashboard tras éxito.

### HU-002: Lista de Turnos
**Criterios de Aceptación:**
- [ ] Carga de datos desde `turnos.json`.
- [ ] Muestra: Fecha, Hora, Especialidad y Profesional.

### HU-003: Esbozo de Arquitectura (Infra)
**Criterios de Aceptación:**
- [ ] Documento de arquitectura candidata creado.
- [ ] Repositorio oficial sincronizado.
